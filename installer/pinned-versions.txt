# Why this file exists: every dependency here used to be cloned at whatever
# master happened to be that day (`git clone --depth=1`, then `git pull
# --ff-only` on re-runs). On 2026-07-25 ComfyUI removed `interleaved_freqs_cis`
# from `comfy.ldm.lightricks.model`; ComfyUI-LTXVideo still imports it, so that
# pack stopped importing — and because one bad import drops ALL of a pack's
# nodes, every install from that day on failed video generation with
# `missing_node_type`. Nothing in this repo changed. Unpinned dependencies mean
# a stranger's merge can break shipped installs overnight.
#
# Format: <name> <full-40-char-sha>. Blank lines and #-comments ignored.
# `name` matches the custom_nodes directory (or `ComfyUI` for ComfyUI itself).

# end-to-end test: a 4 s I2V clip (through the tiled latent upscale), plus

# 10S_Nodes, now vendored and gone from this file). The cause was the in-app
# button running ComfyUI-Manager `update all` and moving them after the capture.
# That is fixed — the button now re-applies this file instead of pulling — and
# these shas are what a passing render was observed on, not what a capture guessed.

# drift apart. A name missing from this file falls back to the default branch,
# so adding a new pack does not require a pin on day one.

# ── ComfyUI: do not bump without a full video render ─────────────────────────
# This is the revision the project's end-to-end I2V render last passed on
# (2026-07-18). Two independent things used to break on 806e092 (2026-07-25),
# both from ComfyUI core changes. BOTH ARE NOW DEFUSED:
#
#   1. `interleaved_freqs_cis` was removed from comfy.ldm.lightricks.model.
#      ComfyUI-LTXVideo still imports it, so the pack raised on import and
#      ComfyUI registered NONE of its 78 nodes. Defused: the one node the video
#      workflow needed is vendored as RaccoonTiledVAEDecode, and that pack is no
#      longer installed at all.
#
#   2. LatentUpscaleModelLoader now wraps its result in a CoreModelPatcher
#      instead of returning a bare nn.Module. 10S_Nodes' LTXVLatentUpsamplerTiled
#      did `next(upscale_model.parameters())`, which a ModelPatcher does not
#      have -- so an I2V job sampled its steps and then died at the upscale stage
#      with AttributeError. Defused: that node is vendored as
#      RaccoonLatentUpsamplerTiled and unwraps the patcher, accepting both shapes.
#
# So this pin is no longer load-bearing -- it is now just "the last revision a
# video actually rendered on". Bumping it is a deliberate act that needs its own
# verification, not a formality. Images and face swap work on both revisions, so
# "images still generate" is not evidence that a bump is safe. Render a video
# before changing this line.
